# Rig-candidate contact sheets (2026-11-27)

`sheet_<cell>_crops.jpg`: 8 close-ups per cell, ordered as in `picks.csv` (the red circle
marks the detection). `sheet_<cell>_full.jpg`: whole-pano thumbnails of the first four
picks. They were cut from the archived native-resolution panos by a scratch script
(seeded draw, one pano per sequence).

Imagery: Panoramax. Lyon pictures are by Grand Lyon (Licence Ouverte / Etalab 2.0), except
`ede17875-...`, which is by luppano (CC BY-SA 4.0). Bayonne pictures are by sig_bayonne
(Etalab 2.0). The sheets are derivative crops and keep those licences.

`human_verdicts.csv`: Jon's per-pano verdicts (rig / not_rig / unsure) and notes from the
review page, 2026-11-27. `control_picks.csv` and `sheet_lyon_above38_ctrl_*.jpg`: the same
38 deg pixel in 8 random Grand Lyon Ladybug panos with no detection there (seed 38), added
after that review to tell tunnel infrastructure from the rig.
